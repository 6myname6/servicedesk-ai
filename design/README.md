## 重新生成

效果图用 Pillow 脚本绘制，不依赖浏览器：

```bash
python draw_mockups.py
```

需要 `Pillow` 和 Windows 字体（微软雅黑、Consolas）。改脚本里的文案/数字后重跑即可，输出覆盖同目录 PNG。
