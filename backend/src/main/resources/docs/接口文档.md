## 通用约定

### 鉴权

除下列公开接口外，所有接口都需要在请求头携带 JWT：

| 接口 | 说明 |
| --- | --- |
| `POST /api/auth/login` | 用户名密码登录 |
| `POST /api/auth/login/email` | 邮箱验证码登录 |
| `POST /api/auth/register` | 邮箱验证码注册 |
| `POST /api/auth/email/code` | 发送邮箱验证码 |

携带方式：

```
Authorization: Bearer <token>
```

- token 由登录接口返回，有效期 7 天。
- 未携带 / 非法 / 过期 / 已登出：HTTP 401，响应体 `code=401`。
- 角色与数据范围由服务端根据 token 解析，前端传的角色/用户 ID 一律不信任。

### 统一响应结构

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| code | number | 必须 | 200 成功；其余见错误码 |
| message | string | 必须 | 提示信息 |
| data | object | 非必须 | 业务数据；无数据时为 null |

### 分页

请求参数：`page`（从 1 起，默认 1）、`size`（默认 10，最大 100）。

响应 `data`：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| total | number | 必须 | 总记录数 |
| records | object[] | 必须 | 当前页数据 |

### 时间与 ID

- 时间格式：ISO 8601，`yyyy-MM-dd'T'HH:mm:ss`，时区 `Asia/Shanghai`，例如 `2026-10-27T10:30:00`。
- 日期格式：`yyyy-MM-dd`。
- ID 为 number（Long）；前端按字符串处理以避免精度问题。

### 枚举

| 枚举 | 取值 |
| --- | --- |
| 角色 | `REPORTER` / `ENGINEER` / `SUPERVISOR` / `ADMIN` |
| 邮箱验证码场景 | `REGISTER` / `LOGIN` |
| 工单状态 | `NEW` / `ASSIGNED` / `ACCEPTED` / `IN_PROGRESS` / `WAITING_CUSTOMER` / `RESOLVED` / `CLOSED` / `REOPENED` / `CANCELLED` |
| 分类 | `HARDWARE` / `SOFTWARE` / `CONSUMABLE` / `INSTALL` / `COMPLAINT` / `OTHER` |
| 紧急度 | `P0` / `P1` / `P2` / `P3` |
| 事件类型 | `CREATE` / `ASSIGN` / `ACCEPT` / `START` / `WAIT_CUSTOMER` / `RESUME` / `COMMENT` / `RESOLVE` / `CLOSE` / `REOPEN` / `CANCEL` / `ESCALATE` / `AI_SUGGEST` / `ATTACH` |
| 知识库状态 | `PENDING` / `PARSING` / `INDEXING` / `READY` / `FAILED` |
| Agent 状态 | `RUNNING` / `SUCCESS` / `FAILED` / `NEED_CONFIRM` |

### 错误码

| HTTP / code | 含义 | 典型场景 |
| --- | --- | --- |
| 200 | 成功 | — |
| 400 | 参数错误 | 必填缺失、格式错误、状态机不允许的参数、验证码错误或已过期 |
| 401 | 未登录 | token 缺失/过期/登出 |
| 403 | 无权限 | 角色不够、内部备注越权 |
| 404 | 不存在或越权 | 工单/文章/用户不存在；数据范围外统一 404 |
| 409 | 冲突 | 状态已变化、乐观锁失败、用户名/序列号重复 |
| 413 | 文件过大 | 超过上传上限 |
| 429 | 频率限制 | 登录失败过多、AI 配额用尽、验证码发送过于频繁 |
| 500 | 服务端错误 | 未捕获异常 |
| 503 | 依赖不可用 | 模型超时/限流、数据库/Redis 不可用 |

错误响应样例：

```json
{
  "code": 404,
  "message": "工单不存在",
  "data": null
}
```

### 文件上传

- `Content-Type: multipart/form-data`，字段名 `file`。
- 工单附件：`jpg/jpeg/png/pdf/docx/md`，单文件 ≤ 10MB。
- 知识库文档：`pdf/docx/md`，单文件 ≤ 20MB。
- 本地存储路径 `./storage/{bizType}/{yyyyMM}/{uuid}.{ext}`，返回可访问 URL。
- 仅接受本系统返回的 URL 作为 AI 图片输入，防止 SSRF。

### AI 接口约定

- 超时：分类 8s、RAG 10s、Agent 单步 30s；超时返回 503，可重试。
- 失败不写业务数据：分类失败不落工单，Agent 失败保留 run 记录。
- 所有 AI 输出都只作为「建议」，写操作必须人工确认。
- 响应中的 `citations` 必须来自检索结果，不允许模型编造来源。

### 1.4 发送邮箱验证码

#### 1.4.1 基本信息

> 请求路径：`/api/auth/email/code`
>
> 请求方式：`POST`
>
> 接口描述：向指定邮箱发送 6 位数字验证码，用于邮箱注册或邮箱登录
>
> 权限：公开

#### 1.4.2 请求参数

参数格式：application/json

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| email | string | 必须 | 邮箱，≤64 位，需符合邮箱格式 |
| scene | string | 必须 | 使用场景：`REGISTER` 注册 / `LOGIN` 登录 |

请求参数样例：

```json
{
  "email": "zhang@example.com",
  "scene": "REGISTER"
}
```

#### 1.4.3 响应数据

参数格式：application/json

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| data.expiresIn | number | 必须 | 验证码有效期（秒），300 |
| data.cooldownSeconds | number | 必须 | 同一邮箱再次发送的冷却时间（秒），60 |

响应数据样例：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "expiresIn": 300,
    "cooldownSeconds": 60
  }
}
```

#### 1.4.4 业务规则

- 验证码为 6 位数字，存 Redis 不落库，有效期 5 分钟，校验通过后立即删除，禁止重复使用。
- 发送频率：同一邮箱 60 秒内重复请求返回 429；每小时上限 5 次，每天上限 10 次。
- `REGISTER` 场景：邮箱已存在时返回 409「邮箱已被注册」，避免用户填完注册表单才被拒。
- `LOGIN` 场景：为防邮箱枚举，**无论邮箱是否存在都返回 200**，仅对已注册且启用的账号实际投递验证码。
- 邮箱格式非法返回 400；验证码内容不得出现在响应体中，也不得写入日志。

### 1.5 邮箱验证码登录

#### 1.5.1 基本信息

> 请求路径：`/api/auth/login/email`
>
> 请求方式：`POST`
>
> 接口描述：用邮箱 + 验证码登录，返回 JWT 与用户信息
>
> 权限：公开

#### 1.5.2 请求参数

参数格式：application/json

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| email | string | 必须 | 已注册邮箱 |
| code | string | 必须 | 6 位数字验证码，仅 `LOGIN` 场景签发的可用 |

请求参数样例：

```json
{
  "email": "zhang@example.com",
  "code": "483920"
}
```

#### 1.5.3 响应数据

参数格式：application/json

结构与 [1.1.3](#113-响应数据) 完全一致：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| data.token | string | 必须 | JWT |
| data.expiresIn | number | 必须 | 有效期（秒），604800 |
| data.user | object | 必须 | 用户信息，见附录 A.3 |

响应数据样例：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "expiresIn": 604800,
    "user": {
      "id": 2,
      "username": "zhanggong",
      "displayName": "张工",
      "role": "ENGINEER",
      "teamId": 1,
      "teamName": "华东售后一组",
      "status": 1
    }
  }
}
```

#### 1.5.4 业务规则

- 验证码错误、已过期、已使用或尝试次数超过 5 次，统一返回 400「验证码无效或已过期」，不区分具体原因。
- 邮箱未注册或未收到验证码，同样返回上述 400，**不暴露邮箱是否存在**，与 1.4 的防枚举策略保持一致。
- 账号已停用返回 403「账号已停用」，由管理员在系统管理中恢复。
- 登录成功即签发新 token，旧 token 不主动失效，仍按有效期自然过期。

### 1.6 邮箱注册

#### 1.6.1 基本信息

> 请求路径：`/api/auth/register`
>
> 请求方式：`POST`
>
> 接口描述：用邮箱验证码注册报修人账号，注册成功后直接返回 token
>
> 权限：公开

#### 1.6.2 请求参数

参数格式：application/json

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| email | string | 必须 | 邮箱，≤64 位，全局唯一 |
| code | string | 必须 | 6 位数字验证码，必须是 `REGISTER` 场景签发 |
| username | string | 必须 | 登录名，3-32 位，全局唯一 |
| password | string | 必须 | 密码，8-32 位，需同时包含字母与数字 |
| displayName | string | 必须 | 显示名，≤32 位 |

请求参数样例：

```json
{
  "email": "zhang@example.com",
  "code": "483920",
  "username": "zhangsan",
  "password": "Passw0rd!",
  "displayName": "张三"
}
```

#### 1.6.3 响应数据

参数格式：application/json

与 [1.1.3](#113-响应数据) 一致：返回 `token`、`expiresIn`、`user`，注册成功即完成登录，前端无需再调登录接口。

响应数据样例：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "expiresIn": 604800,
    "user": {
      "id": 12,
      "username": "zhangsan",
      "displayName": "张三",
      "role": "REPORTER",
      "teamId": null,
      "teamName": null,
      "status": 1
    }
  }
}
```

#### 1.6.4 业务规则

- **注册唯一入口是邮箱验证码**，不提供「用户名 + 密码直接注册」，也不允许自助选择角色或团队。
- 验证码必须是 `REGISTER` 场景签发、未使用且在有效期内，否则返回 400；用 `LOGIN` 场景的验证码注册同样返回 400。
- 邮箱已注册返回 409「邮箱已被注册」；用户名已存在返回 409「用户名已存在」。
- 注册成功后固定写入：`role=REPORTER`、`team_id=null`、`status=1`；团队由管理员后续在系统管理中分配。
- 密码使用 BCrypt 存储，接口响应与日志中不得出现明文。

## 附录 B：错误码速查

| code | 场景 | 前端处理 |
| --- | --- | --- |
| 400 | 参数校验失败 / 验证码无效或过期 | 展示字段错误；验证码场景提示重新获取 |
| 401 | 未登录/过期 | 清 token，跳登录 |
| 403 | 角色不够 | 提示无权限 |
| 404 | 不存在/越权 | 提示不存在 |
| 409 | 状态冲突/版本冲突 | 提示刷新后重试 |
| 413 | 文件过大 | 提示大小限制 |
| 429 | 频率限制/配额/验证码发送过频 | 提示稍后再试，按钮置灰倒计时 |
| 503 | 模型/依赖不可用 | 提示稍后再试，保留输入 |
