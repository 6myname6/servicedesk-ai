## 4. 放置约定

| 新增内容 | 放置位置 | 约定 |
| --- | --- | --- |
| REST 接口 | `controller/` | 路径不含 `/api`；只做参数接收、`@Valid`、`Result.success` |
| 用例契约 | `service/XxxService.java` | Javadoc 写清事务边界、幂等性、错误码 |
| 业务实现 | `service/impl/XxxServiceImpl.java` | `@Service` + `@RequiredArgsConstructor`；不注入其他 Service |
| 可复用辅助逻辑 | `service/support/` | 无状态、单职责、只依赖 Mapper 与领域对象 |
| 纯业务规则 | `domain/` | 不依赖 Spring、不访问数据库 |
| 表映射 | `entity/` | `@TableName`，字段与 ER 图一致，逻辑外键 |
| 自定义 SQL | `mapper/` | 优先用 Lambda Wrapper；必须自定义时才写 `@Select` 或 XML |
| 请求模型 | `dto/request/<模块>/` | 带 Bean Validation |
| 响应模型 | `vo/` | `@Builder` + `final` 字段，不暴露实体 |
| 安全组件 | `security/` | 只服务鉴权，不放业务逻辑 |
| 前端接口封装 | `src/api/` | 只写 URL 与参数，不写业务判断 |
| 前端页面 | `src/views/<模块>/` | 一个路由一个文件；原型页挂 `PrototypeBadge` |

## 5. 命名约定

| 对象 | 规则 | 示例 |
| --- | --- | --- |
| Java 包 | 全小写，按层分包 | `com.servicedesk.service.impl` |
| 实体 | 表名大驼峰 | `ticket_event` → `TicketEvent` |
| Mapper | `<实体>Mapper` | `TicketMapper` |
| Service 接口 / 实现 | `<域>Service` / `<域>ServiceImpl` | `SlaPolicyServiceImpl` |
| 请求 DTO | `<动作>Request` | `TicketCreateRequest` |
| 响应 VO | `<资源>VO` / `<资源>ItemVO` | `TicketDetailVO` |
| 枚举 | 枚举名 = 数据库存储值 | `IN_PROGRESS` |
| 前端组件 | PascalCase | `SlaRemaining.vue` |
| 前端 API 方法 | 动词 + 资源 | `pageTickets` / `createTicket` |
| 工单号 | `TK` + `yyyyMMdd` + 6 位序列 | `TK20261115000001` |

## 6. 空包说明

以下包只有 `package-info.java`，属于**预留占位**，当前无实现：

- `dto/request/ai`、`dto/request/kb`、`dto/request/report`
- `dto/response`
- `common/annotation`
- `domain/sla`

阅读代码时不要误以为遗漏，它们对应尚未落地的 AI / 知识库 / 报表模块。
